# Mersin Toprak Lastik — V2

Premium kurumsal ana site + Google Ads odaklı hizmet sayfaları.

## Ana sayfa
- Premium Hero
- Hizmet kartları
- Goodyear bölümü
- Güven / neden biz
- Kampanya CTA
- Gerçek işletme fotoğrafı
- Google yorumlarına yönlendirme
- Konum ve iletişim
- Mobil sabit Ara / WhatsApp / Yol Tarifi

## Ads landing pages
- /lastikci/

## Teknik
- Responsive / mobile-first
- Yerel mağaza görseli WebP
- Native CSS reveal animasyonları
- Telefon / WhatsApp / yol tarifi CTA dataLayer eventleri
- robots.txt + sitemap.xml
- Google Maps iframe lazy-load
- LocalBusiness + TireShop additionalType JSON-LD

Not: Google Ads / GA4 ölçümü için gerçek Google tag ID ve conversion label bilgileri siteye ayrıca bağlanmalıdır. Google yorumları da uydurulmamış, Google profilinden görüntülenmeye yönlendirilmiştir.
